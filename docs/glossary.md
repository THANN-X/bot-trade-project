# Glossary

ศัพท์ที่เจอระหว่างทาง — เติมเองเมื่อเจอคำใหม่ อธิบายด้วยภาษาตัวเอง

| คำ | ความหมาย |
|---|---|
| OHLCV | Open, High, Low, Close, Volume ของแท่งเทียนหนึ่งแท่ง |
| Slippage | ส่วนต่างระหว่างราคาที่เห็นกับราคาที่ได้จริง |
| Drawdown | พอร์ตลดลงจากจุดสูงสุดก่อนหน้ากี่ % |
| Look-ahead bias | backtest เผลอใช้ข้อมูลอนาคต ทำให้ผลดีเกินจริง |
| Walk-forward | จูนพารามิเตอร์บนช่วงหนึ่ง แล้วทดสอบบนช่วงถัดไปที่ไม่เคยเห็น |
| Holdout | ข้อมูลช่วงสุดท้ายที่กันไว้ แตะได้ครั้งเดียวตอนเลือกกลยุทธ์เสร็จ |
| Hexagonal / ports & adapters | แกนกลางไม่รู้จักโลกภายนอก คุยผ่าน port (interface) ที่ adapter มาเสียบ |
| Port | "ปลั๊ก" ที่แกนกลางกำหนดรูปร่าง เช่น `MarketData`, `Broker` |
| Adapter | โค้ดที่คุยกับโลกจริงและเสียบเข้า port เช่น อ่าน CSV, ต่อ exchange |
| Overfitting | จูนจนเข้ากับข้อมูลอดีตพอดีเกินไป ใช้กับอนาคตไม่ได้ |
